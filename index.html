Workspace

프로젝트와 최근 작업을 앱 첫 화면에서 바로 시작합니다.

홈 화면은 프로젝트 폴더와 최근 대화의 흐름을 분리합니다. 다크/라이트 모드 모두 브랜드 로고와 검색, 설정, 새 채팅 액션이 같은 위치에 유지됩니다.

  • Customer Data Analysis, Security Compliance Center, Legal Document Review
  • 최근 문서 요약과 회의 메모를 빠르게 재진입
  • 하단 채팅 액션으로 새 작업을 즉시 시작

Document AI

계약서와 업무 문서를 채팅 흐름 안에서 검토합니다.

문서 프로젝트에는 대화 목록, 첨부 파일 컨텍스트, 모델 선택, 긴 응답 결과가 한 화면의 작업 맥락으로 이어집니다.
